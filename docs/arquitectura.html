OBSERVAR

APRENDER
El LLM infiere el mapeo (sin reglas)
🧠
Cerebro de aprendizaje (Gemini) Compara snapshots origen vs. destino e infiere campo→campo + tipo de transformación cerebro_aprender.py · gemini-flash
🗺️
Mapa aprendido (JSON) navigation_flow + field_mappings + confianza + razonamiento
💾
Se guarda 1 vez por cliente Upsert en mapas_aprendidos — no se vuelve a llamar al LLM para mapear aprender_flujo.py
3
EJECUTAR
El bot lo hace solo, con datos nuevos
📥
Lee el pedido nuevo del cliente Recorre el portal guiado por navigation_flow (1 o varias pantallas) leer_portal_guiado.py
🔄
Aplica el mapa (sin LLM = gratis) directa · conversión caja→pieza · formato_fecha · lookup_catálogo + resuelve nombre de producto por significado ejecutar.py · resolver_producto.py
✍️
Llena el portal de Arca + guarda Teclea en arca_portal.html con Playwright e inserta en pedidos / pedido_detalle
